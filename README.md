# افزودن وردپرس پابلانا
برای نصب افزونه‌ی ما روی سایت وردپرس، فقط چند مرحله ساده پیش رو دارید.

## مرحله 1: دانلود افزونه

1. روی دکمه‌ی Code کلیک کنید و گزینه‌ی Download ZIP را بزنید.
2. فایل ZIP افزونه را در رایانه‌تان ذخیره کنید.
> 💡 اگر فایل پس از دانلود به صورت خودکار از حالت فشرده خارج شد، کافی است دوباره آن را به ZIP تبدیل کنید (وردپرس فقط فایل‌های ZIP را می‌پذیرد).

## مرحله 2: نصب افزونه در وردپرس
1. وارد پیشخوان وردپرس خود شوید.
2. از منوی کناری به مسیر افزونه‌ها → افزودن → بارگذاری افزونه بروید.
3. فایل ZIP دانلودشده را انتخاب کرده و روی هم‌اکنون نصب کن کلیک کنید.
4. پس از پایان نصب، اگر افزونه فعال نبود، گزینه‌ی فعال‌سازی افزونه را بزنید.

## مرحله 3: ویرایش فایل .htaccess
برای عملکرد صحیح افزونه، لازم است فایل .htaccess سایت‌تان را ویرایش کنید.
1. وارد فایل‌منیجر هاست یا از طریق FTP به فایل‌های سایت‌تان دسترسی پیدا کنید.
2. در ریشه‌ی وردپرس ، فایل .htaccess را باز کنید.
3. قبل از هر تغییری، از فایل اصلی یک نسخه پشتیبان بگیرید.
4. قطعه‌کد زیر را جایگزین کد قبلی کنید:

```apacheconf
# BEGIN WordPress
<IfModule mod_rewrite.c>
RewriteEngine On
RewriteBase /
RewriteRule ^index\.php$ - [L]
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule . /index.php [L]
</IfModule>
# END WordPress
```
5. فایل را ذخیره کنید و سایت را رفرش کنید.

> ⚠️ اگر پس از ویرایش فایل خطایی دیدید یا سایت در دسترس نبود، نسخه‌ی پشتیبان .htaccess را بازگردانید و با پشتیبانی ما تماس بگیرید.

## مرحله 4: ایجاد توکن دسترسی
1. وارد پنل ادمین وب سایت خود شوید و از منو، Publana را انتخاب کنید
2. گزینه افزودن توکن جدید را کلیک کنید
3. توکن ایجاد شده را کپی کرده و در تنظیمات کانال انتشار خود وارد کنید
